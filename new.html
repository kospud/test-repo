● GitHub Pages ready

Статический сайт — без сервера и сборки

Положи этот файл в репозиторий, включи Pages — и получишь публичную страницу по HTTPS. Никакого Node.js, Docker или бэкенда для такого демо не требуется.

Показать деплой
bash — deploy.sh
# 1. Инициализация проекта
git init
git add index.html
git commit -m "Add GitHub Pages demo"

# 2. Публикация в GitHub
git branch -M main
git push -u origin main

✔ Site published: https://username.github.io/repo-name/
git push -u origin main
⚡

Мгновенный деплой

Достаточно запушить index.html и выбрать main вместе с / (root) в настройках Pages.

🎨

Чистый CSS

Стили находятся прямо в файле: сетки, hover-эффекты, адаптивность и анимация появления блоков.

🧩

Расширяемо

Можно добавить styles.css, script.js, изображения или отдельные страницы — Pages отдаёт обычные статические файлы.

Демо-страница для GitHub Pages. Измени файл, сделай git push — изменения появятся на сайте.
